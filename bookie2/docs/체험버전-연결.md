# 부기2 체험 연결

공개 체험 주소: https://legoschool.github.io/bookie/bookie2/public/

학생 체험에서 책을 펼치고 ‘읽고 이야기하기’를 누르면 준비된 대화가 이어집니다. 학생이 쓴 말과 다시 쓴 생각은 ‘나의 한 페이지’로 옮겨 기록장에 저장합니다. 토끼와 거북이는 토끼의 대화, 다른 책은 읽기 친구의 공통 대화입니다. 실시간 AI 응답은 아닙니다.

체험 배너의 ‘학생·교사 전환’으로 교사가 본문을 배정하고 학생 화면에서 확인할 수 있습니다. 체험 기록과 본문 배정은 현재 탭의 세션 저장소에 남아 새로고침 후 복원합니다. ‘체험 초기화’는 이 체험 자료를 초기 상태로 돌립니다. 실제 학생 정보는 입력하지 않습니다.

진단 체험 응답은 채점하거나 저장하지 않습니다. 교사 진단 화면은 미리 준비한 가상 예시이며 학생 체험 응답과 무관합니다. 실제 학생용 서버는 아직 공개 화면에 연결하지 않았습니다.

검증: 로컬 Chrome에서 기존 진단 제출·독서·기록·교사 배정 흐름, 준비된 대화·초안 전달·새로고침 복원·본문 변경 반영·초기화를 확인했습니다. 모바일 폭 390px에서 화면 넘침과 JavaScript 오류가 없었습니다.
